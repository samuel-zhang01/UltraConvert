UltraConvert 1.9.0 adds quieter startup, clearer native Settings and optional compression controls.

- **Start minimized at login** in Settings → General keeps the converter closed when macOS launches it at login. Open Converter, Settings and Quit remain available from its menu bar icon even without folder rules. Opening files and in-app update recovery still show the converter. Off by default.
- Native **General / Updates / Finder** Settings panes with remembered navigation, aligned action buttons, readable explanations and feedback next to each action.
- Optional per-category **Custom quality** sliders for supported lossy image, audio and video outputs. Audio shows a duration/bitrate-based size estimate; actual size varies. Quality 100 can still be lossy. Custom media profiles use 48 kHz audio. Omitted quality keeps established defaults; lossless/fixed profiles stay unchanged.
- **Report** now opens readable, selectable batch outcomes, full errors and notes, with Copy and Reveal controls. **Activity → Details…** opens complete selectable recovery text. Larger helper text, standard Mac Hide/Window commands, relevant queue context menus and clearer mixed-batch format guidance.
- Homebrew tests now upgrade the real previous signed app and verify preferences, rules and Finder actions survive, including when automatic Finder repair is off.

**Update through Homebrew:** finish your batch and quit the app, then run in order:

```sh
brew update
brew upgrade samuel-zhang01/ultraconvert/ultraconvert-runtime
brew upgrade --cask --greedy samuel-zhang01/ultraconvert/ultraconvert
```

Open UltraConvert from Applications afterward. Runtime-first protects Finder actions during the first upgrade from an older cask. Settings and saved rules are retained; ordinary Quit/Homebrew upgrade does not restore a queued batch. For an in-app update with queued-file restoration, use UltraConvert → Check for Updates… instead.

Normal Homebrew removal retains Finder actions. Optional `brew uninstall --zap --cask ultraconvert` removes only this app’s owned actions while still preserving saved rules, preferences, converted files and unrelated services.

All full-release downloads are included: universal installer ZIP/DMG, app-only update ZIP, source archive, release metadata, signed appcast and SHA-256 checksums. The universal app is Developer ID signed, Apple-notarized and stapled; the signed DMG is not separately notarized. Intel compilation is verified; physical Intel hardware remains untested.
