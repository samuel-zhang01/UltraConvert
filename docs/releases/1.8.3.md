UltraConvert 1.8.3 is a small maintenance release for real GitHub updates and Homebrew installation.

- Fresh Homebrew installations can use a managed conversion runtime. Existing installations keep their working per-user runtime.
- Settings includes **Open Download Page…** for a manual installer or repair download.
- Read-only `--version` and `--check-setup` commands support installation verification.
- Version-tag releases now run CI, Developer ID signing, Apple notarization, complete packaging/checksums, public download verification, custom-tap publication and Homebrew installation tests before publishing the signed appcast.

**Install with Homebrew:** `brew install --cask samuel-zhang01/ultraconvert/ultraconvert`. If the same signed app is already installed, quit it first and use `--adopt`. The custom tap is maintained by UltraConvert and is not an official Homebrew Core/Cask submission.

**Update an existing 1.8 app:** choose **UltraConvert → Check for Updates…**, then **Install Update → Install and Relaunch**. Preferences and saved folder rules are retained. Existing engines are separately maintained.

The full installer ZIP/DMG, app-only updater ZIP, source archive, release metadata, signed feed and SHA256 checksums are included. The universal app is Developer ID signed and Apple notarized with its ticket stapled. The DMG is signed and is not separately notarized. Intel compilation is supported; physical Intel testing remains unverified.

The release controller waits for Apple’s notarization ticket before validating the exported app. Homebrew tests validate real JSON → YAML output and apply custom-tap audit rules without the official catalogue’s popularity requirement. Package integrity, repository status and installation checks remain enabled.

**Completed verification:** real production GitHub updates **1.8.0 → 1.8.2 → 1.8.3** downloaded, installed and relaunched on an Apple Silicon Mac. The queued file, selected format/destination, all 11 persistent preferences and saved-rule bytes survived both updates. Post-update conversion kept the original file. Local Homebrew source installation, conversion tests and adoption of the existing app passed; the adopted app remains signed, notarized and accepted by Gatekeeper.
