UltraConvert 1.9.1 improves feedback for longer video conversions.

- Single-file audio and video conversions report live encoding progress when duration is known.
- Turn on **Custom quality** for one video, pick a quality, then click **Estimate Size…**. UltraConvert encodes short temporary samples using the selected profile. The result is approximate and can vary with the content. Changing quality requires a new estimate.
- Tested MPEG transport stream input with an `.mkv` filename and MP4 output.

Install via **Settings → Updates → Check for Updates…**, download the universal release, or upgrade the [Homebrew tap](https://github.com/samuel-zhang01/homebrew-ultraconvert). Originals are kept.
